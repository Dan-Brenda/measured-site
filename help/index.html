How to use Measured Size

Measured Size shows your bra size in each store's own labels. Choose how you shop, then follow the steps. Every step has a picture.

Which one do I need?

On a computer

In Chrome, Microsoft Edge, Brave and Firefox. Add Measured Size, then click its button on any bra listing. Microsoft Edge and Brave add it from the Chrome Web Store too, with the same steps.

Chrome, Edge or Brave Firefox

On an iPhone

Get the free app, enter two measurements, and shop inside it with your size on every bra. You can also use it in Safari.
